Framework Architecture

Test Specs11 .spec.ts files — call page object methods and assert results. No raw Playwright code.
Fixturesfixtures/pageFixture.ts — injects all page objects per test + blocks 7 ad networks globally.

Problem Solving

Key Challenges Solved

⚡
Cloudflare 524 Timeouts
Site returns 524 errors as valid HTML. Added detection for "timeout occurred" after every navigation with automatic page reload and retry.
🛡
Ad Overlays Blocking Clicks
Full-page iFOREX modals covered the checkout button. Blocked 7 ad networks via page.route() globally in fixtures + dismissAdModal() as fallback.
📸
Visual Test Font Timeout (WebKit)
WebKit's document.fonts.ready exceeded 5s. Fixed by blocking all font file requests so fonts resolve instantly, plus 60s snapshot timeout.
🔍
Search Navigation Race Condition
waitForLoadState resolved on the current page before navigation. Replaced with clickAndWaitForNav using URL-based detection.
